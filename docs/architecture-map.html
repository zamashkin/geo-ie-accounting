IE Ledger: map of the app

A bookkeeping and 1% small-business tax tool for Georgian individual entrepreneurs. You upload bank statements, the app books them as double-entry transactions in GEL at NBG rates, and works out each month's return.

What happens when you upload a statement

  1. UploadXLSX or CSV, up to 5 MB, sent to the API. The file itself is never stored.
  2. Detect + parseimporters recognises the BoG format and reads each line.
  3. Match accountBy IBAN + currency, or a new bank account is set up.
  4. DedupeFingerprints skip lines that are already booked, across CSV and XLSX.
  5. PreviewSuggested category per row; you change it or skip the row.
  6. CommitNBG rate per day, double-entry postings, audit row, all in one transaction.
  7. Declaredomain computes the monthly return lines, rate and deadline.

Every transaction has two postings that sum to zero, e.g. the bank account +1,180.00 GBP against Income −1,180.00 GBP. A database trigger refuses anything that doesn't balance. Conversions go to FX Clearing, so they never count as income.

Crossing the limit moves the whole month of crossing and the rest of the year to 3%. All rates, limits and deadlines live in one dated rules file in domain.

  • A cross-tenant test hits every /v1/orgs/:orgId route as another org's user and expects a refusal.
  • Property-based tests (fast-check) for money and ledger maths.
  • No live network in tests: NBG responses and statements are recorded fixtures.
  • Real bank statements stay in a gitignored folder and are never committed.

Built vs. planned

  • Real sign-up and sign-in, workspaces with roles (owner, accountant, viewer)
  • BoG statement import with preview, dedupe and commit
  • Transactions with NBG rates, details and reversal
  • Monthly declarations and dashboard, computed on request
  • Audit log, idempotent writes, daily NBG rates
Parked for later
  • Background imports with file storage and live progress (SSE)
  • Categorisation rules engine, TBC statements
  • Stored and filed declarations, drift detection
  • Manual transactions, invoices, accountant mode, exports
